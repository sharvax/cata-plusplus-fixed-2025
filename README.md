# Cata++ (Fixed for 2025 Experimental CDDA)

A fully patched version of the classic **Cata++** mod, updated to work with the latest Cataclysm: Dark Days Ahead experimental builds (as of **July 2025**).

## ✅ What’s Fixed

- Removed deprecated fields like `"difficulty"` from recipes
- Restored `"difficulty"` to missions (required!)
- Purged all invalid items (`subsuit_xl`) from professions
- Removed deprecated flags like `"STURDY"`
- Deleted `fac_food_supply` references that caused hard crashes
- Verified clean loading on July 2025 experimentals

## 📦 Installation

1. [Download the latest release](#) *(insert link here)*
2. Extract the folder into your `data/mods/` directory
3. Enable the mod when creating a world

## 🔧 Requirements

- Base game only — no additional mods required
- Tested with `cdda-experimental-2025-07-14-0107`

## ℹ️ About Cata++

Cata++ expands core CDDA with:

- Faction stories
- Mutant professions
- Bio-weapon NPCs
- Missions and items
- Deep lore with a light touch of weird

Originally created by **Noctifer-de-Mortem** and contributors from the CDDA modding community.  
This version is a maintenance update to ensure compatibility with modern CDDA versions.
